# 🌱 Plant Enterprise Pro - Smart Greenhouse System

## 🚀 Overview
This project is a complete enterprise-grade Smart Greenhouse & Plant Management system including:

- Flutter Mobile App
- Flask/FastAPI Backend
- JWT Authentication System
- PostgreSQL Database
- MQTT IoT Integration
- AI Disease Detection
- Docker Deployment
- Microservices Architecture
- Cloud Ready (AWS / Azure)

---

## 🧠 Architecture

```
Frontend (React / Flutter)
        |
API Gateway (Flask)
        |
------------------------------------------------
| Auth Service | Plant Service | AI Service |
| IoT Service  | Notification  | Analytics   |
------------------------------------------------
        |
 PostgreSQL + MQTT Broker + Redis
```
